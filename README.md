# FitAI Coach

## Σύνοψη
Το FitAI Coach είναι μια εγγενής (native) Android εφαρμογή σχεδιασμένη να λειτουργεί ως ένας εξατομικευμένος ψηφιακός βοηθός γυμναστικής και ευεξίας. Η εφαρμογή ενσωματώνει το Google Gemini API (μοντέλο gemini-2.5-flash) για την παραγωγή προγραμμάτων γυμναστικής, διατροφικών συμβουλών και καθοδήγησης ευεξίας, προσαρμοσμένων στο προφίλ του χρήστη.

## Βασικά Χαρακτηριστικά
- **Δημιουργία Προφίλ Χρήστη**: Ο χρήστης μπορεί να καθορίσει το τρέχον επίπεδο φυσικής κατάστασης (Αρχάριος, Μεσαίος, Προχωρημένος) και τον κύριο στόχο του (Μυϊκή Ανάπτυξη, Απώλεια Βάρους, Αντοχή, Γενική Ευεξία).
- **Διεπαφή Συνομιλίας**: Διεπαφή συνομιλίας σε πραγματικό χρόνο για την αλληλεπίδραση με το μοντέλο παραγωγικής τεχνητής νοημοσύνης.
- **Διατήρηση Συμφραζομένων**: Η εφαρμογή διατηρεί το πλαίσιο της συνομιλίας μέσω διαχείρισης κατάστασης (multi-turn state management), αποστέλλοντας το πλήρες ιστορικό σε κάθε κλήση του API.
- **Τοπικό Ιστορικό**: Οι συνομιλίες αποθηκεύονται αυτόματα τοπικά. Ο χρήστης μπορεί να προβάλει μια λίστα προηγούμενων συνεδριών, να τις φορτώσει για να συνεχίσει τη συνομιλία ή να τις διαγράψει.
- **Ασύγχρονες Λειτουργίες**: Τα αιτήματα δικτύου προς το Gemini API εκτελούνται σε νήματα παρασκηνίου (background threads) για τη διασφάλιση της ομαλής λειτουργίας της διεπαφής χρήστη (UI), συνοδευόμενα από ενδείξεις φόρτωσης.

## Αρχιτεκτονική και Τεχνολογίες
- **Πλατφόρμα**: Android (Ελάχιστο SDK 26, Target SDK 36)
- **Γλώσσα Προγραμματισμού**: Java
- **Ενσωμάτωση API**: Η επικοινωνία RESTful API υλοποιείται αποκλειστικά με τις πρότυπες βιβλιοθήκες της Java (`HttpURLConnection`), χωρίς τη χρήση εξωτερικών εξαρτήσεων.
- **Αποθήκευση Δεδομένων**: Αξιοποίηση του `SharedPreferences` του Android για τοπική αποθήκευση, με χρήση JSON serialization για την κατάσταση των συνομιλιών.
- **Ασφάλεια**: Το κλειδί του API (API key) διαχειρίζεται με ασφάλεια μέσω του αρχείου `local.properties` και ενσωματώνεται κατά τη μεταγλώττιση (compile time) με τη χρήση του `BuildConfig` του Gradle. Αυτό διασφαλίζει ότι το κλειδί δεν περιλαμβάνεται στο σύστημα ελέγχου εκδόσεων (Git).

## Οδηγίες Εγκατάστασης
1. Πραγματοποιήστε κλωνοποίηση (clone) του αποθετηρίου (repository) στον υπολογιστή σας.
2. Ανοίξτε το έργο στο Android Studio.
3. Αποκτήστε ένα κλειδί Gemini API από το Google AI Studio.
4. Δημιουργήστε ή επεξεργαστείτε το αρχείο `local.properties` στον κεντρικό φάκελο του έργου και προσθέστε την ακόλουθη γραμμή:
   ```properties
   GEMINI_API_KEY=AIzaSyCxvCVgJI9uKjD3zvQRq1LbTp6q579IvQg
   ```
5. Πραγματοποιήστε συγχρονισμό του έργου με τα αρχεία Gradle.
6. Κάντε μεταγλώττιση και εκτελέστε την εφαρμογή σε Android Emulator ή σε φυσική συσκευή.
